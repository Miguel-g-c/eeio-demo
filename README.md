# EEIO-DEMO

Just an example for testing environmentally extended input-output (EEIO) models.

## Modules

### calc

A collection of calculation functions.

### model

The simple EEIO model for running examples.

## Scripts

### emision_factors

A script that shows how to solve an EEIO model, get the emission factors,
and use the model as background system to model a new activity.

## Tests

### test_inflation

A test to show that applying inflation rates before solving the model or after
doesn't matter as one of the main assumptions of IO models is that they are linear.
